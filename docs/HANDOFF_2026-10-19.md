## 1. What changed

| Area | Before | After |
|---|---|---|
| Customer space | One crowded page with the staff sidebar | 4 pages under a bank-style banner: `/client` (home: balance, actions, last operations), `/client/comptes` (accounts, card, operations by day, spending over 30 days, statement), `/client/messages`, `/client/aide`; bottom tab bar on mobile |
| Conversation list | Customer saw their own name | Advisor's name (or « En attente d'un conseiller ») and the subject; staff see « Supprimée par le client » |
| Delete a conversation | Not possible | « Supprimer » with a confirmation dialog; the advisor gets a live pop-up |
| Second conversation | Opened silently (the AI then ignored it) | « Vous avez déjà une conversation en cours… » + « Reprendre ma conversation en cours » |
| Login | Demo-accounts box with a hard-coded password | Removed (no demo e-mail or password in the bundle); « Connexion réussie » before the space opens; « Vous êtes bien déconnecté » after sign-out |
| Staff spaces | Sidebar scrolling inside one long page | Same banner for every role, one route per need (table below); « Plus » menu when items overflow; menu panel on mobile |
| Customers | Nobody could open a complete customer | « Clients » page for advisors and supervisors, « Clients » tab for the admin: login, profile, account and card in one form; temporary password generated and shown once |
| Dashboards | KPI tiles only | Supervisor: load per queue, today's contacts (stacked bar), waiting trend; advisor: live activity strip and queue bars |
| Motion | Almost none | Animated logo intro on the first page of a visit (BNP-style, ~2.4 s, once per session); page transitions and a progress bar between pages; a launch screen while the session is secured; landing hero, playing chat preview, counters, marquee, scroll reveals, parallax; animated login story. All off under reduced motion |

## 2. Run it

1. Start the backend of branch `integration/ai-frontend` on **http://localhost:8080** (its
   `docs/integration/HANDOFF_2026-10-19.md` explains how, with a local database).
2. Here:

```bash
npm ci
npm run build
npm start          # http://localhost:3000 — the backend only accepts this origin
```

The API address comes from `NEXT_PUBLIC_API_URL` (default `http://localhost:8080/api/v1`).
To see the logo intro again, open a new private window (it plays once per browser session).
